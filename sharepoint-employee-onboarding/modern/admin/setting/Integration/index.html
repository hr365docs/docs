Webhook Integration in Employee Onboarding 365

A step-by-step guide to sending task details from Employee Onboarding 365 to Power Automate.

Overview

The Webhook integration lets Employee Onboarding 365 send task details to an external flow, such as a Power Automate flow, as soon as a task is completed for a selected process. The flow receives the task data and can use it in further steps, or pass it on to another application or system.

How it works at a glance

  • A Power Automate flow is created with an HTTP trigger, which generates a unique URL.
  • That URL is added as a webhook in Employee Onboarding 365, linked to a process (for example Onboarding) and one or more tasks.
  • When the selected task is completed, Employee Onboarding 365 sends the task data to the URL and the flow runs.

Prerequisites

  • Admin access to the Settings area of Employee Onboarding 365.
  • Access to Power Automate (https://make.powerautomate.com) with permission to create flows.
  • Premium licensing may be required in Power Automate, because the HTTP request trigger is a premium connector. Please confirm with your administrator.

Part 1: Create the Flow in Power Automate

The Webhook URL is generated by Power Automate, so create the flow first.

Step 1: Start an instant cloud flow

  • Open Power Automate and click Create in the left navigation.
  • Under Start from blank, select Instant cloud flow.

Step 2: Choose the trigger

  • In the Build an instant cloud flow window, scroll the trigger list and select When an HTTP request is received (connector: Request).
  • Click Create. The flow opens with a trigger step named manual.

Step 3: Add a Compose action

  • Below manual, click the + button.
  • In Add an action, under Built-in tools, select Data Operation.

  • Select Compose.

Step 4: Set the Compose input to the request body

  • In the Compose action, open the Parameters tab and click the Inputs field.
  • Click the lightning bolt button (Enter the data from previous step) and select Body under manual.

  • Inputs now shows a Body token. This makes the flow capture the full task data sent by Employee Onboarding 365. Click the manual trigger next.

Step 5: Save the flow and copy the URL

  • Click Save in the top toolbar. After saving, click the manual trigger.
  • The HTTP URL field now shows the generated URL. Click the copy icon next to it.

Note: The URL is generated only after the flow is saved. Before saving, the field shows “URL will be generated after save”.

Important: Treat this URL as a secret. Anyone with the link can trigger the flow.


Part 2: Add the Webhook in Employee Onboarding 365

Step 6: Open the Webhook settings

  • In Employee Onboarding 365, click the Settings (gear) icon in the left navigation.

  • In the Integrations section, click Web hook. The Webhook Integration panel opens and lists existing webhooks with their process, active status, and actions.

Step 7: Add a new webhook

In the Webhook Integration panel, click Add. The Add Web hook panel opens.


Fill in the following mandatory fields:

Field Description Example
Web hook Name A name to identify this webhook Onboarding Process
Task Process The process the tasks belong to Onboarding
Task(s) One or more tasks that will trigger the webhook when completed IT Equipment Assigned
Web hook URL The HTTP URL copied from Power Automate https://default73ca128b1cb8…
Active Toggle to enable or disable the webhook On


Step 8: Paste the URL and save

  • Paste the copied URL into Web hook URL. Use the + button next to the field if you need to add more than one URL.
  • Make sure Active is turned on.
  • Click Save.

What Happens Next

Once the selected task is completed for the chosen process, Employee Onboarding 365 sends the task details to the webhook URL and the Power Automate flow runs. The Compose action holds the data received from the task. To view the data, open the flow in Power Automate, go to its Run history, and open a run to see the output of the Compose step.

Viewing the Task Data After the Flow Runs

  • In Power Automate, open the flow and go to its Run history, then open the run you want to check.
  • Click the Compose step.
  • Under Outputs, click Show raw outputs to see the full data in JSON format.

The raw output contains two groups of details:

Group Fields
TaskDetials TaskName, TaskAssignedTo, TaskStatus, TaskStartDate, TaskEndDate, TaskRemarks
UserDetails EmployeeName, EmployeeEmail, EmployeeContactNumber, EmployeeDepartment, EmployeePosition, EmployeeEmployeeType

Note: The group name appears as TaskDetials in the payload. Use this exact spelling when referring to it in expressions or in a Parse JSON schema. Fields that have no value are returned as null.

Passing the Data to Another Place & Extending the Flow

The Compose step is a starting point. After the Compose step, click + and add more actions to automate further:

  • Add Parse JSON to turn the output into individual fields (such as TaskName or EmployeeEmail) that later steps can use.
  • Send an email or a Microsoft Teams notification about the completed task.
  • Create or update records in SharePoint, Excel, or another system.
  • Pass the data to another application using an HTTP action or connector.

Troubleshooting

Issue What to check
Flow does not run after task completion Confirm the webhook is Active and the correct process and task are selected.
HTTP URL not visible in Power Automate Save the flow first, then reopen the manual trigger.
Flow runs but data is empty Check that the Compose input is set to Body from the manual trigger.
Flow does not trigger at all Make sure the flow is turned on in Power Automate.

AI Integration


Azure OpenAI within EO365 enhances course creation and employee training by automatically generating introductions, questions, and chapters. This eliminates manual effort, ensures grammatical accuracy, and accelerates the onboarding process with smart AI assistance.


To enable this functionality, navigate to Integrations and open the AI API Integration panel.


Inside the panel, configure the following options for Azure OpenAI:

  • Enable Azure OpenAI — Use the toggle to turn AI integration On or Off.

  • Azure AI Endpoint — The REST API or service endpoint hosted on Microsoft Azure.
  • Azure AI API Key — Authentication token required for secure connection with Azure AI services.
  • Azure AI Deployment Name — Identifier of the deployed AI model in your Azure resource.

    • To learn how to generate and retrieve your Endpoint, API Key, and Deployment Name refer this Guide: Configure Azure AI Documentation.

After entering the required details, click Save to activate the integration.


Courses

  • Add Course Details — Enter the course name and description, then click Next to continue.


  • Generate Course Introduction — Click AI Generate to automatically create a professional introduction for the course.


  • Refine & Correct — Add your own edits, or click AI Generate again to polish and fix grammatical errors.




Questions

  • Generate with AI — Instead of manual entry, click Generate Questions using AI.


  • Set Parameters — Define type, section, answer format, difficulty, number of questions, and time limit, then click Generate.


  • Review Questions — AI generates questions with options and correct answers based on your inputs.


  • Select & Customize — Choose required questions, edit as needed, or select all for quick setup.


  • Save — Finalize by clicking Save or Save as Draft.



Chapters

  • Generate with AI — Click Generate Chapters using AI instead of creating them manually.


  • Set Parameters — Define type, section, difficulty level, number of chapters, and time limit, then click Generate.


  • Review Chapters — AI generates structured chapters based on your prompt, which can be refined or customized.


  • Save — Store your work by clicking Save or Save as Draft.
