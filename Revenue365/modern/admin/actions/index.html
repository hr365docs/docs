Client Agreements

This knowledge base explains the Client Agreements feature in Revenue 365, including how to open Client Agreements, review existing agreements, and add a new agreement.

1. Client Agreements – Overview

Client Agreements is available from the Revenue 365 navigation under the Actions section. The Client Agreements page provides access to existing agreements and an Add option for creating a new agreement.


2. Open Client Agreements

From the Revenue 365 application, open the Actions menu and select Client Agreements. The Client Agreements option is highlighted in the screenshot, showing the navigation path to the agreement module.

  1. Open the Actions menu from the left navigation.
  2. Select Client Agreements.
  3. The Client Agreements page opens.


3. Client Agreements List

The Client Agreements page displays the existing agreements in a grid. The page provides an Add button for creating a new agreement, a Search option, column-level search fields, and agreement information such as client, agreement name, dates, auto-renewal, signed date, and status.

  • Use Add to create a new client agreement.
  • Use the Search box to search the agreement list.
  • Column search fields are available for the displayed agreement columns.
  • The grid displays Client Name, Agreement Name, Agreement Start Date, Agreement End Date, Auto renewal, Agreement Signed Date, and Status.
  • The screenshot shows an existing agreement with its status displayed as Completed.

4. Add a Client Agreement

Select Add from the Client Agreements page to open the Add Agreement form. The form contains client and organization information, agreement dates, renewal settings, an agreement template option, and an area for attaching the agreement file.

  • Client *: Select the client for whom the agreement is being created.
  • Client Email *: The client's email address is displayed for the selected client.
  • Organization Name *: Select the organization associated with the agreement.
  • Organization Email *: The organization's email address is displayed.
  • Agreement Start Date *: Select the date on which the agreement starts.
  • Agreement End Date *: Select the date on which the agreement ends.
  • Auto renewal: Use the toggle to configure the renewal option shown in the form.
  • Agreement Template: Select an agreement template when applicable.
  • Upload Agreement: Attach the agreement document using the upload control.
  • The form provides a file-selection/attachment area where the agreement document can be selected or attached.

6. Creating a Client Agreement – Step-by-Step

  1. Open the Revenue 365 application.
  2. Open the Actions menu.
  3. Select Client Agreements.
  4. On the Client Agreements page, select Add.
  5. Select the required Client.
  6. Verify the displayed Client Email.
  7. Select the required Organization Name.
  8. Verify the displayed Organization Email.
  9. Select the Agreement Start Date.
  10. Select the Agreement End Date.
  11. Configure Auto renewal using the displayed toggle when required.
  12. Select an Agreement Template when applicable.
  13. Attach the agreement document using Upload Agreement.
  14. Review the entered agreement information before completing the creation process.

7. Client Agreement List – Available Information

  • Client Name: Identifies the client associated with the agreement.
  • Agreement Name: Identifies the agreement record.
  • Agreement Start Date and Agreement End Date: Show the agreement validity period.
  • Auto renewal: Displays the renewal setting for the agreement.
  • Agreement Signed Date: Displays the signed date when available.
  • Status: Displays the current status of the agreement.
  • The list includes search controls for locating agreement records.

8. Important Notes

  • Fields marked with an asterisk (*) in the supplied Add Agreement screenshot are required fields.
  • The screenshots show example data; use the appropriate client, organization, dates, template, and agreement file for the actual agreement.
  • This KB describes only controls and fields visible in the supplied screenshots. No additional save, approval, notification, or renewal behavior is assumed because it is not demonstrated in the provided screenshots.
  • The screenshots are intentionally kept in process order: navigation → agreement list → Add Agreement form.

Client Creation

This knowledge base explains how to access the Clients module and create a new client in Revenue 365. The content and field descriptions are based on the screenshots provided.

1. Access the Clients Module

Open the Actions menu from the Revenue 365 navigation and select Clients. The Clients option is highlighted in the screenshot.

  1. Open the Actions menu.
  2. Select Clients.
  3. The Clients page opens.

2. Clients List Page

The Clients page displays client records and provides client views, filters, search, and management actions. The Add button is highlighted and is used to begin client creation.

  • All Clients displays the client list.
  • Direct Clients and Partner Clients provide separate client views.
  • Filter Set provides Common Filters.
  • The visible filters are Client Name, Organization, Churn Risk, Health Score, CSAT, Sentiment, and Status.
  • Select Add to open the client creation form.
  • Use Search to search the client list.
  • Column search is available for Client Name, Organization Name, Client Billing Country, Status, and Client Email.

3. Add Client

Select Add from the Clients page to open the Add Client form. The form contains General, Contacts, and Documents tabs. The supplied screenshot shows the General tab.

The General tab contains organization, client, partner, identification, payment, currency, customer segment, tenant, and address information. Fields marked with * are shown as required.

5. Client Creation – Steps

  1. Open Revenue 365.
  2. Open Actions.
  3. Select Clients.
  4. Select Add.
  5. Select the required Organization.
  6. Select a Partner when applicable.
  7. Enter or select the Client Name.
  8. Review the Client ID.
  9. Enter Tax ID when applicable.
  10. Select Payment Terms.
  11. Select Currency.
  12. Select Customer Segment when applicable.
  13. Enter Tenant ID and Tenant Alias when applicable.
  14. Enter Client Address details.
  15. Enter Billing Address details, or use Same As Client Address when applicable.
  16. Review the information and continue with the available client creation action.

6. Other Tabs in Add Client

  • General: Contains the client and address information shown in the supplied screenshot.
  • Contacts: A separate tab for client contact information.
  • Documents: A separate tab for client-related documents.
  • The supplied screenshots do not show the fields inside Contacts or Documents, so this KB does not define their fields or behavior.

7. Important Notes

  • Fields marked with * are shown as required in the supplied Add Client screenshot.
  • The visible values are example data and should be replaced with the appropriate client information.
  • Review the required organization, client, currency, and address information before completing client creation.
  • This KB documents only the controls and fields visible in the provided screenshots.
